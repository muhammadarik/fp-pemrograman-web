# FP Pemrograman Web  
_Aplikasi Sistem Service Laptop & Penjualan Produk_

---

## 📌 Deskripsi Proyek  
Proyek ini merupakan tugas akhir/“Final Project” untuk mata kuliah **Pemrograman Web**, yang dibangun menggunakan **PHP Native**, MySQL, dan Bootstrap 5. Proyek ini berfokus pada aplikasi sistem manajemen service laptop dan penjualan produk, tanpa menggunakan sistem POS penuh, melainkan menonjolkan fitur-layanan, CRUD multi-role (admin, teknisi, pelanggan), manajemen data produk, layanan, invoice, dan riwayat status.

---

## 🎯 Fitur Utama  
- Sistem multi-role: **Admin**, **Teknisi**, dan **Pelanggan**  
- CRUD data produk (dengan kategori), layanan service, pelanggan, booking, invoice, history status, notifikasi  
- Upload dan edit gambar untuk produk  
- Tombol “Buat Invoice” hanya muncul jika service status = “selesai” dan belum memiliki invoice  
- Tampilan dashboard terpisah bagi admin, teknisi, dan pelanggan  
- Detail service dan riwayat status ditampilkan dalam modal Bootstrap 5 untuk pelanggan  
- Struktur direktori terpisah untuk admin dan landing page user  

---

## 🛠️ Teknologi yang Digunakan  
- Backend: **PHP Native**  
- Basis data: **MySQL**  
- Frontend: **Bootstrap 5**, HTML5, CSS3  
- Struktur proyek dengan arsitektur sederhana untuk memudahkan pengembangan dan pemeliharaan  
- Gambar & upload: dukungan untuk upload gambar produk melalui fitur CRUD  
- Directory: `admin/`, `pages/`, `inc/`, dan lainnya sesuai kebutuhan
